# Product

## Register

brand

## Users

Linux filesystem developers, open-source contributors and researchers exploring
persistent memory for LLM agents. They need to understand the primitive, reproduce
the experiment and assess evidence before extending it.

## Product Purpose

Position MoobFS first as an experimental native filesystem for persistent LLM
memory and context. Explain that agent applications select memories and assemble
context, while the filesystem stores and exposes them. Present read-only shared
storage as the implemented M1 foundation, with retrieval and agent integration
clearly marked as future work. Provide a direct technical path to code, format,
validation and decisions. The user explicitly chose both presentation and technical
documentation, rather than choosing only one.

## Brand Personality

Precise, experimental, transparent. Show storage behavior and measured results;
make limitations as easy to find as the idea.

## Anti-references

Avoid a commercial SaaS presentation, invented performance claims, ornamental
status dashboards and visuals that imply unimplemented agent capabilities.

## Design Principles

- Lead with LLM memory and context; explain shared bytes as the current foundation.
- Show independent identities converging on shared bytes.
- Put reproducibility one step from the explanation.
- Separate tested implementation from future architecture.
- Link decisions and evidence to versioned source.

## Accessibility & Inclusion

Target WCAG AA contrast, visible keyboard focus, semantic navigation and readable
mobile layouts. No required animation; honor reduced-motion preferences if added.
English site with a clearly linked Portuguese project guide.
